# 检索、筛选、导入与全文获取

## 检索与可复查清单

按当次主题拆分研究对象、方法、任务和评价问题，组合中英文检索词。先查直接相关论文，再顺着相关工作的引用与被引关系扩展。以当次日期解释“近三年”等相对范围，说明采用的年份口径。

用户要求数量不足以筛出可靠论文时，报告实际数量和原因，不凑数；未指定数量且需要完整流程时，可先选约 5 篇紧密相关论文，并说明这个起始规模。不要以用户的研究方向替代其当次主题。

候选表建议包含：标题、作者/年份、期刊或会议、DOI 或稳定链接、相关性、推荐理由、PDF 是否可得。摘要筛选标为摘要筛选；精读状态留给全文处理。通过论文官方页面、DOI 信息或机构来源核实身份。不要根据搜索摘要猜测 DOI、卷期、实验设置或结果。

先核对 DOI（小写、去掉 DOI URL 前缀），再核对标题、作者与年份，检查 Zotero 是否已有记录。标题近似的预印本与期刊版需核实版本关系；不要自动合并不同论文。文章预印本版本日期、在线发表日期与卷期年份分别记录，保留实际阅读版本。

用户要保存检索过程时，将日期、检索词、候选/筛选理由和来源链接写入库的 `_系统/资料/检索记录`；重要的综述与回答写到 `问答`，不另造根目录分类。

## Zotero 准备

使用当前会话提供的 Zotero 技能。从技能目录或当前插件缓存中的 `zotero/*/skills/zotero/SKILL.md` 定位它，阅读后使用同目录下的 `scripts/zotero.py`。插件缓存通常在 `~/.codex/plugins/cache/openai-curated-remote`；不要把版本号写死。

先运行 helper 的 `status --json`。在此 Mac 上，回环请求应绕过系统代理；Python helper 可按如下方式执行（参数里的路径以当前实际路径为准）：

```bash
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost python3 /实际路径/zotero.py status --json
```

Zotero 没打开时可通过可用的应用控制工具启动；本地 API 没启用时按 Zotero 技能处理。正常工作通过 `http://127.0.0.1:23119`；本地 API 只读、不需要云端 API key。不要向 `/api` 发写请求，也不要直接改 Zotero 的 SQLite 或 storage 目录。

## 授权、目标与导入

- 用户仅说“找文献”“先列清单”时，不导入。用户说“导入”“找好直接整理”“完整流程”时，在其范围内继续，不重复确认相同动作。
- 导入前调用 `selected-target --json`，并查询 `collections --json`；Connector 导入到 Zotero **当前选中的库/分类**，helper 的导入命令没有指定分类参数。
- 用户指定分类时，核实唯一的精确名称与 key，通过应用 UI 选择对应分类，再查 `selected-target` 确认。分类不存在且用户已要求导入到该新分类时，可在个人库内创建并验证；不要虚构 API 参数或改数据库。
- 未指定分类且已授权导入时，可沿用个人库中当前选中的位置，执行前说明实际目标。当前选中群组/共享库、目标无法判定或存在歧义时，先澄清目标，继续独立检索工作。

从已核实元数据生成 BibTeX/RIS，保存到 `_系统/资料/导入记录`，再运行（仅在有导入授权后）：

```bash
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost python3 /实际路径/zotero.py selected-target --json
NO_PROXY=127.0.0.1,localhost no_proxy=127.0.0.1,localhost python3 /实际路径/zotero.py import-ris --file /已核实的绝对路径/selected.ris --yes
```

BibTeX 使用 `import-bibtex`。运行前检查 helper 的当前参数，不向不支持的选项传分类 key。

小批执行，保存导入会话与返回结果；用本地 API 查询导入后的实际条目，验证标题、作者、DOI、年份、所属库/分类和 item key。超时或响应不确定时，先核实是否已写入，避免再次导入产生重复。已存在条目通常复用，不擅自合并、覆盖元数据或删除附件。

## PDF 全文

导入书目与添加 PDF 是不同步骤，分别报告结果。优先出版商开放获取版、机构仓库和作者公开预印本。检查文件确为可读 PDF，核对首页标题、作者与版本，避免保存登录页或 HTML 为 PDF。

通过 Zotero 提供的附件功能或当前已核实的 Connector 保存功能，将 PDF 附加到准确的父条目；helper 的 RIS/BibTeX 导入不保证自动下载 PDF，也没有已验证的任意附件上传命令。必要时使用应用 UI；不要猜测端点、复制文件到 storage 或直接改数据库。

添加后查询条目的 children，确认附件的父条目、类型、本地可打开性。已获得全文授权时，可获取附件 file URL；用实际附件 key 交给文献库脚本继续处理。没有取得全文时保留书目并标明限制；需要学校订阅登录或用户提供 PDF 时再说明具体缺口，不承诺所有论文都有全文。

全文翻译仅在用户要求时执行，并保留原文供核对。若用户希望自行决定翻译工具，先说明选项与差别，由用户选择；不自动切换服务或上传全文。
